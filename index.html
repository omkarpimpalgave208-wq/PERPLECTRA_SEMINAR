Wrap an existing action
python
# Before: an unprotected agent action def scale_up_instances(region: str, count: int): # ... your existing logic pass # After: wrapped with PERPLECTRA protection import perplectra from perplectra import RecoveryMode @perplectra.protect( intent="Scale up EC2 instances in the given region", recovery_mode=RecoveryMode.AUTO_ROLLBACK, target_env="production", max_retries=2, ) def scale_up_instances(region: str, count: int): # Your existing logic -- unchanged. # PERPLECTRA captures baseline, validates intent, # monitors execution, and recovers on failure. pass # Execute normally -- PERPLECTRA handles the rest. scale_up_instances(region="us-east-1", count=3)
The @perplectra.protect decorator preserves your function's original signature and return type.
Planned: supports both synchronous and async functions.
Planned: recovery is applied only when PERPLECTRA detects a verified failure condition.

Protect an action

Define the intent, target, and recovery policy for an AI agent action before execution.

Must match the function name in your codebase.
Auto rollback
Automatically rolls back to the last known-good state if failure is verified.
Compensating action
Execute a defined compensating operation to undo side effects.
Safe halt
Halt and page the on-call engineer. No automated recovery attempted.
Low
Reversible, isolated
Medium
Partial impact possible
High
Broad system effect
